# Baseline screenshots

One PNG per route, taken by `npm run smoke` at 1280×900 with animations
switched off. They are committed on purpose: a baseline that lives only on
one laptop compares a page against nothing.

A `*.now.png` beside a baseline is what the last run saw when it differed.
Look at the pair, then either fix the page or accept the new picture with
`npm run smoke -- --bless`.
